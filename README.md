# GTA 6 Video Auto Bot V2

Aucun lien d'image à fournir.

Le bot :
1. génère le sujet et le script ;
2. cherche automatiquement des visuels sur les pages officielles Rockstar GTA VI ;
3. télécharge plusieurs images valides ;
4. génère la voix ;
5. crée une vidéo verticale ;
6. ajoute la voix ;
7. dépose la vidéo dans les Artifacts GitHub Actions.

Par défaut : AUTO_PUBLISH=false
